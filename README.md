# To-Do List (Flutter)

A simple to-do list app built with Flutter. Add tasks, delete them just as easily, and enjoy a clean purple interface.

## Features

- Add tasks
- Delete tasks
- Purple-themed interface

## Tech stack

- Flutter
- Dart

## Run it locally

You'll need the [Flutter SDK](https://docs.flutter.dev/get-started/install).

```bash
git clone https://github.com/mirelalexy/to-do-list-flutter.git
cd to-do-list-flutter
flutter pub get
flutter run
```

This was built with an older version of Flutter and hasn't been updated since. If `flutter run` complains about dependencies, try `flutter pub upgrade`.

## About this project

My first project in Flutter, built to learn the basics of the framework, such as widgets, state, and layout. It's a small app, but it's what got me interested in mobile development, which I've since moved on to with React Native in [Chorae](https://github.com/mirelalexy/chorae).
